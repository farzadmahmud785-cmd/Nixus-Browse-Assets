# Nixus-Browse-Assets
Project Nixus's Own Assets for Compiling it Later.
To Compile it into a Executeable:

1. Download these Ingredients:
	1.Node.js
	2.Git(Optional)
	3.Electron

2. Put the Folder in the (C:\) Drive and Open Run CMD As Administrator
3. Type in the Following Commands:
	cd..
	
	cd..
	
	npm install

	npm run start

	npm run build

4. After That's Done, You Should See Your Custom Made Browser Inside C:\Project Nixus\Gist\

Thank You And Have Fun Building Your Own Browser
